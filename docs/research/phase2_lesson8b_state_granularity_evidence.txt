read:
 - the coarse model's OWN value function is optimistic garbage
   (projection error); only the lifted rollout tells the truth.
 - bin(3) loses a few percent; bin(10) is visibly degraded —
   the (s,S) structure needs enough resolution to place the
   reorder point.
 - rule of thumb: bin where the value function is FLAT, keep
   resolution where it bends (the reorder region).
